# InfraLink — downloads

InfraLink links your own computers and phones on your local network: shared folders,
remote terminals, one clipboard, and AI agents that can use every device. End-to-end
encrypted. No account, no cloud.

## Installing

- **macOS:** open the disk image and drag InfraLink to Applications. The app is not yet
  notarized: the first time, right-click InfraLink → Open.
- **Windows:** run the installer (it asks for administrator rights once). It is not yet
  code-signed: if SmartScreen appears, choose More info → Run anyway.
- **Android:** open the APK on the phone and allow installing from that source.

Then create a network on your main computer and add your other devices from
*Add device* (computers type a code; phones scan a QR code).

This repository only hosts installers. Older versions remain under
[Releases](https://github.com/yashasraj615/InfraLink-Releases/releases).
